홈개인정보처리방침이용약관English

Mail Dashboard는 개발자 본인이 개인 용도로만 사용하는 메일·할 일·일정 확인용 대시보드입니다. 일반에 배포되거나 판매되지 않으며, 개발자 본인 외의 사용자는 없습니다.

개인정보처리방침

1. 접근하는 Google 사용자 데이터

  • Gmail: 받은편지함의 안 읽은 메일 목록과 본문 조회, 다른 메일 계정에서 받은 메일을 Gmail에 추가, 분류용 라벨 생성
  • Google Tasks: 할 일 목록 조회 및 완료 표시 변경
  • Google Calendar: 일정 조회(읽기 전용)

2. 이용 목적

위 데이터는 사용자 본인의 화면(대시보드)에 새 메일, 할 일, 일정을 표시하고, 사용자 본인의 다른 메일 계정에 도착한 메일을 본인 Gmail로 모아 보기 위한 목적으로만 사용합니다. 광고, 분석, 프로파일링, 인공지능 학습 등 다른 목적으로는 사용하지 않습니다.

3. 저장 및 보관

  • 인증 정보(갱신 토큰)와 처리 기록은 사용자 본인이 소유·관리하는 개인 서버에만 저장됩니다.
  • 메일 본문은 화면에 표시할 때만 불러오며 별도로 저장하지 않습니다.
  • 개발자가 운영하는 외부 서버나 제3자 클라우드로 데이터를 전송하지 않습니다.

4. 제3자 제공

Google 사용자 데이터를 어떠한 제3자에게도 판매, 공유, 이전하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

Mail Dashboard가 Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

6. 접근 권한 철회 및 삭제

Google 계정 권한 페이지에서 언제든지 Mail Dashboard의 접근 권한을 해제할 수 있습니다. 권한을 해제하면 저장된 토큰은 더 이상 사용할 수 없으며, 개인 서버에 저장된 토큰과 기록 파일은 직접 삭제할 수 있습니다.

  2. 본 앱은 있는 그대로 제공되며, 메일·할 일·일정 표시의 정확성이나 지속적인 동작을 보증하지 않습니다.
  3. 사용자는 Google 서비스 약관 및 관련 법령을 준수하여 본 앱을 사용합니다.
  4. 본 약관과 개인정보처리방침은 사전 고지 후 변경될 수 있으며, 변경 시 이 페이지의 최종 수정일을 갱신합니다.

English summary

Mail Dashboard is a personal dashboard used only by its developer. It is not distributed to or used by anyone else.

Data accessed: Gmail (read unread inbox messages, add messages received at the developer's other mail account, create a label), Google Tasks (read and mark tasks complete), and Google Calendar (read-only).

Use: solely to display the developer's own mail, tasks and events on a personal screen, and to collect the developer's own mail from another account into Gmail. No advertising, analytics, profiling, or AI model training.

Storage: OAuth tokens and processing logs are stored only on a personal server owned by the developer. Message bodies are fetched for display and not stored. No data is sent to third-party servers.

Sharing: Google user data is never sold, shared, or transferred to any third party.

Limited Use: Mail Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation: Access can be revoked at any time at myaccount.google.com/permissions.

Terms: Provided as-is for the developer's personal use only, without warranty.
